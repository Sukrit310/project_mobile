# ฟอนต์ภาษาไทยสำหรับ MoneyMate

แอปฝัง Noto Sans Thai เพื่อให้ข้อความภาษาไทยแสดงผลสม่ำเสมอและใช้งานได้ออฟไลน์ โดยไม่ต้องดาวน์โหลดฟอนต์ขณะเปิดแอป

- แหล่งที่มาอย่างเป็นทางการ: https://github.com/google/fonts/tree/main/ofl/notosansthai
- ไฟล์ต้นฉบับ: `NotoSansThai[wdth,wght].ttf`
- URL ดาวน์โหลด: https://raw.githubusercontent.com/google/fonts/main/ofl/notosansthai/NotoSansThai%5Bwdth%2Cwght%5D.ttf
- ไฟล์ในแอป: `NotoSansThai.ttf` (เปลี่ยนชื่อไฟล์เท่านั้น ไม่แก้ไขข้อมูลฟอนต์)
- ดาวน์โหลดเมื่อ: 2026-11-11
- สัญญาอนุญาต: SIL Open Font License 1.1 ดู `OFL.txt` ซึ่งนำมาจากโฟลเดอร์ต้นฉบับเดียวกัน
