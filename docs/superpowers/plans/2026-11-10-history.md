# History Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent form/history work, with root integration and a final read-only review.

**Goal:** Implement a usable History tab, filters and edit/delete flows.
**Architecture:** One repository stream feeds Home or History; the existing form
supports both creating and editing. Explicit repository operations preserve IDs.
**Tech Stack:** Existing Flutter, Firebase Auth/Firestore and tests; no new packages.
**Spec:** `docs/superpowers/specs/2026-11-10-history-design.md`

## Global Constraints

- Preserve the current five-field Firestore schema and integer satang.
- No existing user data is changed by agent verification.
- Work in the current workspace (no Git repository).
- No Stats/Budget feature or schema migration in this step.

## Review Focus

- Editing a remotely deleted record must not recreate it.
- Month filtering compares year as well as month and sorts a copy.
- Editing preserves ID and original date/time unless the user changes the day.
- Cancelled/failed deletion must not show a success message.
- Actual live deletion needs the updated owner-only rules published separately.

## Interfaces

`TransactionRepository`: existing APIs plus `Future<void> updateTransaction(MoneyTransaction)`
and `Future<void> deleteTransaction(String id)`. `TransactionNotFoundException` is
a const domain exception in `transaction_repository.dart`.

`TransactionFormScreen`: existing constructor plus `MoneyTransaction? initialTransaction`.
It calls the injected onSave, pops true on success, and uses edit-specific labels.

`HistoryScreen({required List<MoneyTransaction> transactions, required DateTime initialMonth,
required Future<void> Function(MoneyTransaction) onEditTransaction,
required Future<void> Function(MoneyTransaction) onDeleteTransaction,
required VoidCallback onAddTransaction,
required ValueChanged<int> onDestinationSelected, String? notice})`.

`MoneyMateNavigationBar({required int currentIndex, required ValueChanged<int> onTap})`.
`Home` adds `ValueChanged<int>? onDestinationSelected` (existing fallback retained).
